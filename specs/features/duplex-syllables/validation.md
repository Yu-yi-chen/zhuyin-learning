# 雙拼音 — Validation

## 驗收清單

### 資料

- [ ] `DUPLEX_TABLE` 涵蓋 18 個聲母，無多無少
- [ ] `DUPLEX_FINALS` 固定 11 個韻母，順序正確（ㄚ ㄛ ㄜ ㄞ ㄟ ㄠ ㄡ ㄢ ㄣ ㄤ ㄥ）
- [ ] `DUPLEX_WORDS` 至少涵蓋 80% 的有效組合（其餘顯示佔位）
- [ ] 所有 `word` 的 `zhuyin` 陣列長度 = 中文詞的字數
- [ ] EN / JP 翻譯皆有填寫

### 頁面

- [ ] 路由 `/duplex` 可正常訪問
- [ ] Navbar 顯示，返回按鈕導航至 `/`
- [ ] Sidebar 顯示熊熊 + 等級卡片

### 格子表

- [ ] 表格列數 = 18（聲母數）
- [ ] 表格欄數 = 11（韻母數）+ 1（列標題欄）
- [ ] 有效組合顯示可點擊格子（2 個符號）
- [ ] 無效組合顯示 — 不可點擊
- [ ] 點擊有效格子 → WordPopover 出現，顯示代表詞
- [ ] 點擊已開啟的格子 → WordPopover 關閉
- [ ] 點擊其他格子 → 舊 popover 關閉，新 popover 開啟
- [ ] 點擊 popover 外部或按 Escape → popover 關閉

### WordPopover

- [ ] 桌機：popover 優先顯示於格子上方
- [ ] 空間不足時顯示於格子下方
- [ ] 水平位置不超出視窗邊界
- [ ] `DUPLEX_WORDS` 有對應資料 → 顯示插圖佔位框、中文詞、注音、譯文
- [ ] `DUPLEX_WORDS` 無對應資料（null entry）→ popover 顯示「（待補充）」佔位

### 語言切換

- [ ] EN 模式顯示英文譯文
- [ ] JP 模式顯示日文譯文
- [ ] 切換語言時，中文詞與注音不變

### 版面響應

- [ ] 桌機（> 768px）：表格完整顯示，不需橫向捲動
- [ ] 手機（≤ 768px）：表格可橫向捲動，欄標題固定可見

### 首頁卡片

- [ ] 首頁顯示 5 張卡片（原有 4 張 + 雙拼音）
- [ ] 點擊雙拼音卡片導航至 `/duplex`
- [ ] 卡片順序符合學習路徑（地圖 → 雙拼 → 結合韻 → 三拼 → 聽力）
- [ ] 聽力測驗卡片橫跨全寬
