# 三拼音 — Validation

## 驗收清單

### 頁面基本

- [ ] 進入 `/syllables` 顯示三個 tab：ㄧ 系 / ㄨ 系 / ㄩ 系
- [ ] 切換 tab 時表格內容正確更換，active 狀態清除
- [ ] 有效格子顯示三個符號（聲母 + 結合韻兩符號）
- [ ] 無效格子顯示 —，不可點擊
- [ ] 格子樣式與符號地圖一致
- [ ] 頁面包含熊熊側邊導覽列（Sidebar）

### 播放

- [ ] ~~點擊有效格子 → 播放三個符號依序發音~~（**音訊暫停用，待後續版本**）
- [ ] 點擊後格子進入 active 狀態（黃底 + 下壓效果）

### 置中大卡（WordPopover）

- [ ] 點擊有效格子後，畫面中央彈出大卡 + 半透明遮罩
- [ ] 卡片寬 400px（手機不超出視窗，左右保留邊距）
- [ ] 卡片顯示：插圖區（240×240，Phase 1 為佔位框）、中文詞（大字）、注音標記（直式排列）、EN/JP 譯文
- [ ] 卡片右上角顯示關閉按鈕（✕），點擊關閉卡片
- [ ] 每個有效格子有獨立的代表詞（不與結合韻共用）
- [ ] 語言切換時，譯文更新
- [ ] 點擊遮罩 → 關閉卡片
- [ ] 按 Escape → 關閉卡片
- [ ] 卡片開啟期間，對應格子保持 active 樣式
- [ ] 切換 tab 時，卡片關閉（無選中格子）

- [ ] JP 模式：標題「三拼音」

### 首頁入口
