# Pronunciation Scoring — Requirements（Phase A 原型）

## 頁面

### R1：獨立測試頁
- 路由 `/pronounce`，不在首頁放入口（測試用，直接打網址）
- 版面沿用現有 `page-layout` + Navbar（返回首頁）+ Sidebar
- 內容：目標詞卡（插圖 + 中文 + 注音）、聽範例鈕、錄音鈕、結果區、換詞鈕

### R2：目標詞來源
- 取自 `words.js` 的 37 個例詞（已有插圖 + 音檔可當範例）
- 預設隨機一個；「換一個」鈕可切換

## 錄音

### R3：錄音流程
- 使用 `MediaRecorder` API；首次點錄音時才請求麥克風權限（不預先索取）
- 狀態機：`idle` → `recording` → `scoring` → `done`（可回 `idle` 重錄）
- 錄音中顯示錄音動畫 + 「停止」鈕；上限 5 秒自動停止（避免過長）
- 權限被拒 / 裝置不支援 → 顯示友善說明，不崩潰

### R4：音訊格式
- `MediaRecorder` 預設格式（各瀏覽器不同：webm/opus 或 mp4/aac）
- 送 API 前轉 base64；**不寫入任何儲存**（隱私，見 plan.md）

## 評分

### R5：Gemini 評分（Phase A）
- 模型：`gemini-2.5-flash`（支援音訊輸入，額度較 TTS 寬鬆）
- 送出：錄音 base64 + 目標詞 + 注音 + prompt
- prompt 要求回傳 **JSON**：`{ score: 0-100, feedback: "一句中文回饋" }`
- 回傳非 JSON / 解析失敗 → 顯示錯誤，可重錄（不崩潰）

### R6：結果顯示
- **分數 + 一句回饋**（如「85 分 · 聲調很棒！」）
- 分數分級配色：≥80 綠、60–79 金、<60 提示再試（沿用現有色系）
- **不做逐字分析**（Gemini 原型階段這些細節不可靠，做了也是假的）
- 結果區明確標示「原型測試中，評分僅供參考」

## 不做（Phase A）

- 不接積分（`addPoints`）
- 不存任何錄音或分數
- 不放首頁入口
